# PetHub - Pet Care Management System

PetHub is a full-stack web application built using the MERN stack with TypeScript for managing pet profiles, veterinary appointments, and medical records.

## Technologies Used

- Frontend: React, TypeScript, Redux Toolkit, TailwindCSS, Vite
- Backend: Node.js, Express.js, TypeScript
- Database: MongoDB, Mongoose
- Security: JWT, bcryptjs
- Additional Features: jsPDF (PDF Report Generation), qrcode.react (QR Code Generation)

## Main Features

- Role-based authentication for Pet Owners and Veterinarians.
- Complete CRUD operations for Pet profiles.
- Appointment scheduling and veterinary status management.
- Automated PDF clinical slip generation.
- Analytics dashboard displaying pet statistics and activity metrics.
- Printable collar QR code tag for pet identification.
